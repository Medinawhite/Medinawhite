### 🔧 What I've done in production

- **CI/CD with GitHub Actions** — end-to-end workflows for Java (Maven/Gradle), Python and Node apps: build → SonarQube quality gate → Docker image → push to Amazon ECR → `helm upgrade --install` on OpenShift, with one values file per environment (dev / pre / pro).
- **Containers & orchestration** — Dockerfiles, Helm charts, ConfigMaps and Secrets, troubleshooting pods in `CrashLoopBackOff` / `ImagePullBackOff` with `oc logs`, `oc describe` and events.
- **Rehosting legacy apps** — onboarding WAR/EAR/JAR artifacts onto Linux and Windows VMs with JBoss and Apache Tomcat, and promoting them across environments with Ansible playbooks.
- **Operations** — incident resolution through ServiceNow, secrets in HashiCorp Vault, coordination with international teams in Jira and Confluence.
